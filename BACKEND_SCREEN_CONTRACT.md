Shared query rules: permission-filter before pagination or aggregation; no search/filter may expand authorized scope. Missing evidence remains missing rather than zero or confirmed. Counts drill into the same scoped record set. Money is integer paise; quantity/rate is canonical decimal text. Every consequential mutation stores actor, reason, source evidence and audit event in the same transaction. Jobs use stable keys; calculation runs and prior evidence versions remain immutable.

Implemented wiring checkpoints: authentication/invitations use `access`, `invitations`, `invitationDelivery` and verified provider-event interfaces. Configuration and guided setup use `configuration`. Intake uses `intake`, `intakeJobs` and `projections`; accepted evidence feeds `manufacturer`, `returns`, `credits` and `stock`. Receipt images/PDFs use `documents` and checked protected delivery. Case and variance queries expose separate quantities, integer-paise values, source documents, immutable runs and human actions. `review`/`discussions` own team work and append-only discussion; `reports` owns scoped dashboards/exports; `auditHistory`, `notifications`, `deadlines` and `monitoring` support Administration. `ai`/`aiJobs` own configured-only advisory requests, checked extraction, confirmation, citations, caching and usage reservations. Global filters share the same authorized scope; local search/status stays table-local.

Manual acceptance is pending. Automated malware/DLP scanning was removed from the MVP and deferred in `todo.md`; intake relies on authorization, metadata, templates, bounded structural validation and a no-patient-data declaration. AI has no configured model/key and must show unavailable; controlled management questions are supported rather than unrestricted natural-language queries. Native MFA, external identity events, delivery receipt and production/privacy gates remain deferred in `todo.md`. These function names describe implemented interfaces, not passing end-to-end evidence.
